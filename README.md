# PG Soft Lucky Neko (Kucing Keberuntungan) - Educational Simulation

Simulasi web 1:1 permainan slot **Lucky Neko (Kucing Keberuntungan)** dari PG Soft. Dibangun untuk keperluan literasi, edukasi, dan penelitian rehabilitasi kecanduan judi online di Indonesia, memperlihatkan cara kerja mekanik probabilitas slot, pengganda bertingkat (*cat multiplier*), dan bagaimana algoritma permainan bekerja.

---

## 🎮 Fitur Utama
1. **1:1 Native Visual & Audio:**
   - Menggunakan tekstur asli dan varian *motion blur* untuk setiap simbol (Kucing Keberuntungan, Gong Wild, Koin Scatter, Gendang Taiko, Lentera Merah, Kipas Lipat, Sushi Salmon, Jimat Omamori, serta kartu A, K, Q, J, 10).
   - Audio latar resmi (Shamisen & Koto tradisional untuk putaran normal, dan Taiko bertempo tinggi untuk *Free Spins*).
   - Efek suara lengkap (spin, reel tumble, cat multiplier ding, dan koin kemenangan).

2. **Mekanik Asli Lucky Neko:**
   - 6 Reel cascading dengan format gulungan dinamis hingga 32.400 cara menang (*Ways to Win*).
   - **Fitur Pengali Kucing (+2):** Setiap simbol Kucing Emas yang muncul pada reel menambah nilai pengali sebesar +2.
   - **Wilds-on-the-Way:** Simbol berbingkai perak berubah menjadi bingkai emas saat terlibat kemenangan, dan berubah menjadi Simbol Wild pada runtuhan berikutnya.
   - **Putaran Gratis (Free Spins):** Terpicu saat memperoleh 4 atau lebih simbol Scatter, dengan pengali yang tidak di-reset di antara putaran non-kemenangan.

3. **Keamanan & Kontrol:**
   - Dilengkapi layar kunci PIN 4-digit (Default: `8888`) sebelum permainan dapat diakses.
   - Menu simulasi / demo testing untuk memicu skenario Scatter dan Kucing Emas.

---

## 🚀 Cara Menjalankan

Buka file `index.html` langsung di browser, atau jalankan melalui local server:

```bash
# Menggunakan Python
python -m http.server 8080

# Akses via browser:
http://localhost:8080/index.html
```
